## Work log

Append a short entry after meaningful progress or a session boundary: timestamp, task ID, agent, result/decision, evidence/checks, remaining issue and next action. Correct an inaccurate prior entry by appending a correction rather than silently rewriting history. Avoid transcripts, full tool outputs, secrets and raw sensitive content.

## Resume instruction

Read the current checkpoint, selected task and referenced constraints. Verify that the workspace and unfinished changes match; respect any active owner. Resume the next eligible action within the existing authorization. Update the checkpoint and append a log entry as progress is made. Use a separate handoff only if required context or access is missing.

# Profilo di un ambiente generico

[English](../../../environments/generic.md) | [Italiano](generic.md)

Per una piattaforma sconosciuta:

1. Accertare se è locale o isolata nel cloud.
2. Verificare disponibilità di filesystem, shell e Python.
3. Verificare la raggiungibilità del Vault AWA configurato.
4. Verificare connettori, strumenti e skill effettivamente disponibili.
5. Pubblicare un profilo compatto delle capacità se la persistenza funziona.
6. Contrassegnare le capacità incerte come `UNKNOWN`, senza indovinarle.

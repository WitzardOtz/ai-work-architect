# Indice delle fonti aziendali

[English](../../../templates/organization-sources.md) | [Italiano](organization-sources.md)

Riferimenti privati, non una copia centralizzata dei documenti aziendali. Usare gli ID delle fonti nel profilo. Evitare collegamenti con token o credenziali; limitare anche i metadati quando necessario.

| ID fonte | Titolo / scopo | Riferimento controllato dal chiamante | Categoria: policy / procedura / modello / contesto | Responsabile / autorità e verifica | Revisione / decorrenza | Evidenza sul ciclo di vita / approvazione | Sensibilità e percorso di recupero consentito | Ultima verifica di accesso ed esito | Ambito / passaggi pertinenti |
|---|---|---|---|---|---|---|---|---|---|

Distinguere indisponibile, sconosciuto, obsoleto e non approvato. Un documento leggibile non è necessariamente autorevole o aggiornato. Verificare host e percorso dati consentiti prima di aprire contenuti riservati. Recuperare solo passaggi pertinenti e mantenere le posizioni originali delle fonti.

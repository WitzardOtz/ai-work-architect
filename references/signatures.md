# Task Signature

The Signature describes the problem, never the proposed solution.

## Core dimensions

- `operation`: acquire / transform / analyse / produce / validate
- `input_regime`: text / structured_data / code / image / audio / mixed
- `grounding_regime`: self_contained / project_corpus / external / proprietary / live
- `inference_depth`: minimal / compositional / multi_step / hypothesis_level
- `context_scale`: local / bounded / large / corpus_scale
- `verifiability_regime`: deterministic / empirical / source_grounded / inferential / aesthetic
- `error_consequence`: low / medium / high / critical

## Extended dimensions

Use only when routing changes:

- freshness
- epistemic uncertainty
- context coupling
- output modality
- output contract
- state interaction

Most values should be inferred rather than asked.
